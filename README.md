## Entry

**Ghosting** — 8 characters.

Home Wi-Fi vanishes mid-call, mid-game, mid-download, then comes back like nothing happened.

## How it works

Run `python3 main.py`. It writes the single word to `/output/entry.txt`, with no trailing newline. Output is deterministic: every run writes the same 8 bytes.
